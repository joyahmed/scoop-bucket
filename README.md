# Scoop bucket

Apps by ZettaByte, installable with [Scoop](https://scoop.sh) on Windows.

```powershell
scoop bucket add zettabyte https://github.com/joyahmed/scoop-bucket
scoop install zettabyte/trove
```

| App | What it does |
|---|---|
| [Trove](https://github.com/joyahmed/trove) | A fast file explorer with real tabs, 100,000-file folders and instant search. |
